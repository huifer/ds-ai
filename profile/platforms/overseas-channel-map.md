# 16. 明确排除

## Reddit

本人已明确决定不使用 Reddit，后续系统不得：

- 创建 Reddit 内容计划；
- 自动生成 Reddit 帖子；
- 把 Reddit 作为增长 KPI；
- 建议通过 Reddit 私信获客；
- 要求维护 Reddit 账号；
- 开通 Reddit Ads（即使不依靠 Reddit 内容，也拒绝在其广告平台投放）。

Web Research 在确有必要时是否允许读取公开 Reddit 内容，尚未决定；默认不把它作为本人发布渠道。

## 独立个人网站

在缺少个人品牌影响力、且没有现成可运行 SaaS 产品之前，不建设独立个人网站。当本人拥有第一个具备实际功能与付费转化能力的 SaaS / Agent / 工具站点时，海外 Web 形象可以由该产品站点承担，不另行搭建品牌信息站或单页产品介绍站。

允许的网站形态：

- 可运行 SaaS 产品站；
- Agent 服务站；
- 模板市场站；
- 开发者工具站；
- 多模板矩阵中的某一模板（作为产品）。

不允许的网站形态：

- 单纯品牌故事站；
- 一次性介绍站；
- 每篇只讲一个功能的单页站。

## 付费投放

永久拒绝包括但不限于：

- X Ads、LinkedIn Ads、Instagram Ads、YouTube Ads、Spotify Ads、Quora Ads、Reddit Ads；
- Outbrain、Taboola、BuySellAds、Carbon Ads、Paved、Pressfarm；
- Google AdSense、Google Ad Manager、Ezoic、Mediavine、AdThrive；
- 付费赞助内容、付费网红、付费邮件群发、付费 Placement、付费推文、付费 Newsletter 推广。

任何渠道增长只能依靠：

- 产品自然可见性（SEO、目录收录、Product Hunt、Indie Hackers、Hacker News、开源社区）；
- 共享资产（开源项目、模板、代码、Skill、文档）；
- 长期内容积累（Newsletter、YouTube、博客、案例研究）；
- 社区关系（X、Bluesky、Discord、LinkedIn、YouTube Community）；
- 口碑与推荐（现有用户、用户推荐机制、合作伙伴）。

# 17. 平台选择质量标准

新平台只有满足以下至少两项才进入运营：

- 有明确目标受众；
- 能为产品带来可追踪访问；
- 能沉淀自有订阅或联系信息；
- 能产生高质量产品反馈；
- 能建立技术或商业可信度；
- 维护成本可控；
- 支持自动化但不违反平台规则；
- 与 Ship with Zen 品牌匹配度。

如果连续 90 天无法证明价值，则降级或停止维护。

# 18. 没有付费投放情况下的增长原则

本人不接受任何付费投放。海外增长只能靠：

- 公开资产：开源项目、模板、Skill、示例代码、文档；
- 长期内容：Newsletter、YouTube、博客、案例研究；
- 自然分发：Product Hunt、Indie Hackers、Hacker News、目录、SEO；
- 社区关系：X、Bluesky、Discord、LinkedIn、YouTube Community；
- 口碑与推荐：现有用户、用户推荐机制、合作伙伴。

渠道运营判断“是否值得投入”时应同时回答：

1. 该渠道增长是否依赖付费？
2. 该渠道增长是否依赖 Reddit？
3. 90 天内可验证的价值是什么？
4. 需要多少周维护时间？
5. 与 SaaS 产品或开源项目的可重复使用程度？
6. 是否会污染国内 IP 杭州 OPC 张三的资产？

如果任何一项问题答案是负面，则降级或停止。
