## 证据等级

| 等级 | 定义 | 可用于 |
|---|---|---|
| A | 官方机构、出版社、公开代码仓库、可核验后台或作者提供的原件 | 标书、正式方案、官网、演讲 |
| B | 权威媒体、政府机构转载、城市官方媒体 | 品牌背书、媒体资料包、内容引用 |
| C | 普通媒体转载、第三方平台商品页或目录页 | 辅助佐证，不单独作为关键事实 |
| D | 创始人本人陈述 | 个人叙事；关键数字应补充 A/B 级证据 |
| PENDING | 已知存在，但材料尚未进入本地事实库 | 只用于内部规划，不对外发布 |
