# 杭州：“一人公司”风乍起

2026-06-28 14:57:14  来源：新华每日电讯

钱塘潮涌，奔竞不息。在杭州，一场由人工智能驱动的变革正悄然改变这座“创新活力之城”的创业生态。

  当AI成为“合伙人”，一个人也能成为这股创业浪潮中的“弄潮儿”。这种以“单人+AI即公司”为核心的新型创业形态——一人公司（One Person Company，简称“OPC”）正加速在杭州涌现。为何杭州成为不少年轻人“AI+OPC”创业的首选地？答案藏在政策温度、产业密度与创新浓度里——它们为这些“超级个体”浇筑起从梦想走向“一人独角兽”的桥梁。

2023年10月31日，观众在“人工智能+”展馆参观人工智能产品及应用。当日，以“计算，为了无法计算的价值”为主题的2023云栖大会在浙江杭州云栖小镇开幕，大会为期3天。新华社记者 黄宗治 摄

  **杭州加速成为“AI+OPC”创业新高地**

  在上城区鸿鹄汇一人独角兽创业加速社区，创业者们正忙着调试产品、优化界面、生成文案。与传统创业空间不同，这里不少项目从研发到运营的多项工作，都由创业者一人借助AI工具完成。

  “AI承担了80%的编程工作，我是战略官、产品经理和首席运营官。”“95后”李雲帆在鸿鹄汇成立时就选择入驻。这名计算机专业出身的创业者曾组建团队开发应用软件，后来转型为OPC创业模式。他开发的AI作文批改产品“作文说”，上线4个月用户数量突破1.5万。

  “自2025年9月启动以来，鸿鹄汇累计收到全球创业入驻申请超2000份，引进项目51个，涵盖AI生产力工具、动漫、短剧、AI影视等多个方向。”鸿鹄汇合伙人王家豪表示，在社区的实际运营中，OPC早已跳出“仅限一人经营”的狭义定义，衍生出多元发展形态。

  有的初创项目从单人起步，稳步扩张至30人规模；也有团队预计年营收突破千万元，核心运营人员依旧仅两三人。在王家豪看来，OPC的核心不在于团队人数多少，而是小规模主体依托各类人工智能应用，释放出较强的价值创造力。

  跨越钱塘江，一栋酷似“城市芯片”的蓝白写字楼正是萧山区的“芯模社区”，这里，另一种OPC创业形态正在生长。仓颉智能是典型的OPC企业。一开始，创始团队由张小博和2名合伙人带着AI智能体创业。如今企业主要转向具身智能高质量数据供给，公司也从几个人扩展至60余人。

  “OPC不是终点，而是起点。”张小博说，从OPC起步，靠订单积累和客户信任做大，最终组建起一支几十人的高效团队——他把这称为“STC”（Super Team Company），即超级团队公司。

  萧山区发展和改革局副局长陈渊观察到，辖区内OPC创业的主要有四类群体：“数字经济领域大企业溢出创业类人群、非数字经济领域的转型创业者人群、院校及科研平台的技术人员和毕业硕博研究生、运用AI加持的文化创意人群。”从行业分布看，AI原生类、AI+应用类、AI服务类和AI文创类是OPC最集中的领域。

  创业“种子”逐渐破土成林，而这份生长的力量，也在更广阔的舞台上被看见、被激发。6月29日至30日，首届“AI+OPC”创新发展大会将在杭州举行，相关报告、政策措施和场景清单集中发布，为技术、资本、人才和场景资源进一步汇聚搭建平台。

**杭州何以成为OPC创业首选地**

  作为全国青年发展型城市首批试点，杭州每年吸引超过35万名35岁以下青年扎根逐梦。2025年新引进青年大学生42.9万人，人才净流入率多年位居全国前列。

  年轻人用脚投票，正是杭州创业吸引力的重要体现。何以杭州？答案藏在这里的政策温度、产业密度与创新浓度里。

  ——政府加速筑“巢”。青聚枢纽·未来数智港、浙大城市学院OPC社区、魔搭社区、AIGC产业创新中心、芯模社区、模域空间、才立方OPC社区、钱塘湃OPC社区……放眼全杭州，在一年多的时间里，“AI+OPC”社区纷纷涌现。

  例如，上城区的青聚枢纽·未来数智港，引进超1000万用户的WaytoAGI开源社区，以精细化运营机制打通创业“最后一公里”。上城区科技经信局副局长沈伟霞介绍，除了社区本身为OPC提供的资源，上城区还为社区内OPC配发“AI智能体工具包”，提供低成本公寓，高频组织场景对接会、举办OPC场景共创实战营，邀请专家做社区建设指导，为OPC社区和OPC发展持续提供助力。

  不仅如此，杭州懂趋势，更懂需求。杭州市科技局有关负责人表示，杭州出台了12条政策措施来鼓励OPC创新创业，希望用“真金白银”的投入和“无微不至”的服务，让杭州成为全球“AI+OPC”创新的最强磁场、创业的首选热土。

  此外，杭州市市场监管局针对OPC“轻线下、重线上”的特点，推出“一址多照”“工位注册”——一张桌子、一台电脑就能开公司；在知识产权保护方面，杭州开辟专利审查绿色通道，符合条件的OPC可享受优先审查；在执法监管上，杭州在OPC创业园区探索“沙盒监管”，对纳入观察期的OPC给予1至3年的成长空间，以行政指导、风险提示为主。此外，杭州还建立OPC专属“信用账户”，搭建银企对接桥梁，让信用也能“当钱用”。

  ——“上下楼”就是“上下游”。政策搭台，产业唱戏。在杭州，OPC创业者并非孤军奋战，一个“上下楼”就是“上下游”的产业生态正在形成。

  由余杭区政府与阿里巴巴集团合作共建的“模域空间”里，首批入驻的同济空间、童仁智能等算力代表企业，埃森哲、析引力等数据代表企业，以及翊奇科技、鸿欢网络等模型与智能体方面的代表企业，已初步形成人工智能上中下游产业链基础。

  不仅如此，滨江区西兴街道滨和启梦空间“AI+OPC”社区还为创业者打造了“楼上居住、楼下办公”的住创一体模式，更关键的是订单和服务就在“家”门口。智能跳绳项目创业者阿柄对此深有感触，选择来这里创业正是看中了这里硬件产业链完善，且社区95%以上的居民都是高新企业的青年人才，楼上就能招到硬件工程师，楼下咖啡吧里就能碰到潜在合作方。“这种低成本、强资源、高活力的结合，让创业更安心，也更有信心。”

  ——AI氛围浓厚，产业生态吸引众多创业者。如果说政策是阳光、产业是土壤，那么杭州浓厚的AI创新氛围，就是滋养OPC创业者拔节生长的雨露。

  横空出世的杭州“六小龙”，横跨具身智能、脑机接口、空间智能、大模型与游戏文化等多个前沿领域，是中国AI创新力量的集中展示。不仅如此，杭州拥有阿里千问、DeepSeek等顶尖开源基础大模型，并落地医疗、具身智能等4个国家级人工智能中试基地。

  西湖区“云谷中心”与“魔搭社区”共建的开发者中心于2025年11月正式揭牌。其中，魔搭社区是国内最大的AI模型开源社区，线上汇聚了19万大模型、开放了3万余个数据集。开发者中心首期面积超1万平米，是集社交、技术交流与办公于一体的线下实体空间。开发者中心的创业社区“Y/OUR SPACE杭州云谷站”目前已有180位来自全国各地的OPC开发者入驻。

  一季度，杭州人工智能核心产业营收达1229亿元，同比增长25.2%；截至目前，杭州市已集聚机器人产业相关企业700余家；杭州四足机器人国内市场份额占80%，人形机器人占50%……

  “浓厚的AI创新氛围，让OPC创业者聚焦细分领域，提供敏捷专业化服务，提升产业链效率。”数字经济智库首席研究员胡麒牧认为，年轻创业者追求自主性、灵活性，OPC成为高校毕业生、技术人才低成本创业的重要通道；同时，也有助于激发全域创新动能，吸引海内外人才集聚。

**这股创业浪潮将如何“重塑”城市**

  当“超级个体”遇见“数字之城”，改变的不仅是创业者，更是整座城市的创新生态与产业版图。

  日前，杭州发布了《杭州市打造全国“AI+OPC”创业新高地行动计划(2026—2028年)》，为杭州打造“AI+OPC”创业新高地擘画了清晰蓝图。

  行动计划明确了未来三年的总体目标：到2028年，建成OPC社区100个以上，认定卓越级OPC社区10个以上，培育营收超1000万元的OPC100家以上，集聚高成长性OPC5000家以上，汇聚OPC创新创业人才30000名以上。

  OPC创业浪潮正在潜移默化地改变杭州的创业生态，成为杭州全力构筑一流科创企业孵化地的重要方式。据不完全统计，多个区域已经密集发布措施和指引。例如上城区发布《上城区支持人工智能OPC社区建设的若干政策措施》，为“一人公司”创业者提供从落地服务、场景验证到品牌提升的全方面支持；高新区（滨江）发布人工智能OPC社区建设指引，则关注人工智能OPC社区的建设标准与服务要求。

  “指引的发布，就像是为社区建设加载了‘导航’。”海螺邦OPC社区合伙人桑迪红说，作为运营了10多年的国家级众创空间，海螺邦虽然积累了丰富的运营经验，但“入港的船只变了，港口也要面临提升改造和转型”。在她看来，这些指引能帮助运营主体尽快迭代众创空间模式，更好地助力OPC向“AI+OPC”发展，形成核心竞争力。

  “AI+OPC”创业浪潮也在重塑杭州的产业组织形态。从“一人公司”到超级团队，一种更加灵活、高效的组织方式正在生长。

  对于未来OPC发展趋势，陈渊认为，一是垂直深耕化，从“通用型”转向垂直赛道专业化，聚焦细分领域，如AI医疗、工业设计、跨境直播等形成核心竞争力；二是联盟生态化，从“单打独斗”走向OPC联盟或者共生社区发展，通过资源共享、能力互补，联合承接大型订单；三是规模化分化，少数头部“OPC”突破规模天花板成为“小而强”乃至“一人独角兽”，多数OPC保持“小而美”的垂直专精形态。

  更深远的影响在于，OPC创业浪潮正在重塑杭州作为“人工智能第一城”的创新底座。“十五五”时期，杭州将建设人工智能创新发展第一城、打造更高水平创新活力之城、构建杭州特色现代化产业体系作为重中之重。

  杭州市委相关负责人表示，“十五五”时期，杭州将重点推进“点燃开源引擎”“攻坚具身智能”“深化制度创新”三大核心任务。

  携手AI，这座“数字经济第一城”正加速向“人工智能第一城”迈进。胡麒牧说，从“六小龙”的崛起，到“AI+OPC”创业潮的涌动，杭州正在以人工智能为引擎，驱动一场从技术到产业、从个体到城市的多层次变革。（记者邬焕庆 张璇）
