# Built by one developer. Shipped in production.

TanStack Ship is built and maintained by Huifer, a solo developer who has shipped 12+ production TanStack apps on Cloudflare Workers. Every template here is born from real production pain — not theory.

## Background & Experience

I started building with React in 2017 and moved to TanStack Router/Start as soon as v1 hit stable. Since then, I've shipped production apps using TanStack Router, Query, Table, and Start — dealing with auth flows, Stripe billing, edge deployment, and everything in between.

Every template on this site started as a solution to a real problem I hit in production. The Auth module exists because I spent 3 days debugging session cookies on Cloudflare Workers. The Stripe integration exists because I lost a weekend to webhook signature verification. These are battle-tested patterns, not theoretical architecture.

## Why I Built This

I was tired of starting every new SaaS project from scratch — wiring up the same auth, billing, and routing boilerplate every single time. Existing boilerplates were either too opinionated (forcing their architecture on me) or too minimal (leaving me to build the hard parts myself).

TanStack Ship is my answer: templates that include exactly what you need to ship, nothing you don't. Every piece is there because it broke in production and I fixed it. Every piece I removed was there because a template needed it on paper, but it caused problems in practice.
