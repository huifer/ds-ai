## 使用原则

1. 标书和企业正式材料优先使用 A 级证据。
2. B 级媒体证据使用“某媒体报道”措辞。
3. D 级个人陈述可以用于个人故事，但关键经营数字必须标注来源。
4. 动态 GitHub 指标在发布前刷新。
5. PENDING 事实不进入自动生成的官网、标书或媒体简介。
6. 同名人物资料不得自动合并。
