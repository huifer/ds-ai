# Cash Flow（现金流）

> 内部 skill，无独立命令。供管理层查看公司现金流。

## 调用契约
入参：`{ range }`（如本月 / 本季）

## 流程
1. 聚合所有 account 的 invoice 状态 + 合同付款节点。
2. 计算：
   - **应收**（已开票未回 / 待开票）
   - **应付**（外采 / 人力成本）
   - **净现金流**
   - **预测**（按合同付款节点 + 历史回款周期）
3. 标注现金流风险点（集中到期 / 长期逾期）。

## 返回
现金流摘要 + 预测；供经营决策。
## 约束
属内部敏感财务数据，不外发；脱敏前不得用于公开内容。
