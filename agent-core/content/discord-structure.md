# Discord 频道落地清单

> 用途：`discord_create_channels` 一次性创建。
> 架构原则：`总控` 与 `总编` 平级。`总编` 是顶级 Category。

## 00 · 总控

| Channel | Topic | 用途 |
|---|---|---|
| `#总控台` | chief-agent、scheduler、cost 主面板 | 主编协调 + 状态 |
| `#深度讨论` | 战略、争议、长期决策 | 长期讨论 |
| `#审批中心` | 跨业务审批（标书、报价、合同、外发） | 审批 |
| `#agent-状态` | 8 个 Agent 实时状态与告警 | 监控 |
