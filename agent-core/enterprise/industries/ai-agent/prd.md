# PRD · ai-agent

> 行业 PRD 完整版本见 `agent-core/enterprise/templates/prd/ai-agent.md`。
> 本文件仅做行业要点。

## 行业现状

- AI Agent 从 Copilot 走向 Autonomous；
- 大模型能力提升 + 工具调用能力增强；
- 企业逐步把客服、知识库、销售等流程 Agent 化。

## 主要玩家

- OpenAI / Anthropic / Google（模型提供方）
- LangChain / LlamaIndex（框架）
- 各家垂直 SaaS（客服、CRM、ERP）

## 趋势与风险

- 趋势：多模态、长上下文、工具协议、Agent Marketplace；
- 风险：幻觉、工具误调、合规、成本。

## 设计建议

- MVP：FAQ + 1 个工具；
- Beta：+ 多个工具 + 监控；
- 上线：+ 完整流程 + 客户验收。
