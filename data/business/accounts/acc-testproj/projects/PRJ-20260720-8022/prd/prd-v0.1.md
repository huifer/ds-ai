# 3. Agent 角色与边界

| 角色 | 职责 | 越权红线 |
|---|---|---|
| 入口 | 飞书 / 企微 / Web | — |
| 规划 | 任务拆解、工具选择 | 不直接调用未授权工具 |
| 工具 | 订单 / FAQ / 人转 / 自定义 | 任何写入/外发必须审批 |
| 记忆 | 短期窗口 + 长期向量 | 客户标识必须脱敏 |
| 监控 | 调用日志、成本、失败 | 自动上报 #agent-状态 |

# 4. 工具清单

| ID | 工具 | 权限 | 错误处理 |
|---|---|---|---|
| T-01 | 订单 API 查询 | 读 | 失败转人工 |
| T-02 | FAQ 检索 | 读 | top-1 低于阈值转人工 |
| T-03 | 转人工 | 通知 | 超时 5s 升级 |
| T-04 | 写操作（订单/账户） | 审批 | 任何写必须二次确认 |

# 5. 数据与上下文

| 来源 | 用途 | 隔离 |
|---|---|---|
| 订单系统 | 实时查询 | 单租户 |
| FAQ 文档 | 检索 | 不上传模型 Provider |
| 对话历史 | 短期窗口 | 1 周后清理 |
| 业务知识库 | 长期向量 | 客户维度隔离 |

# 6. 评估指标

- 任务成功率
- 工具调用准确率
- 转人工率
- P95 延迟
- 单会话成本
- 用户评分

# 7. 风险

| ID | 风险 | 等级 | 缓解 |
|---|---|---|---|
| R-01 | 模型幻觉 | 高 | FAQ 兜底 + 二次确认 |
| R-02 | 工具误调 | 高 | 工具白名单 + 审批 |
| R-03 | 数据泄露 | 高 | 脱敏 + 单租户 |
| R-04 | 成本失控 | 中 | 限速 + 告警 |

# 9. 验收标准

- 关键场景覆盖率 ≥ 80%
- 工具调用准确率 ≥ 90%
- 幻觉率 < 5%
- P95 ≤ 3s
- 客户主管签字
