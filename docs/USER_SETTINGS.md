# 用户设置与开关指南

> 本文档说明用户如何控制 AI 的行为

---

## 一、设置概览

### 1.1 设置项清单

| 设置项 | 默认 | 说明 |
|--------|------|------|
| **进度条** | ✅ 开启 | 显示任务执行进度 |
| **详细日志** | ❌ 关闭 | 显示 AI 执行步骤 |
| **对话摘要** | ✅ 开启 | 自动生成摘要写入 Project |
| **自动归档** | ✅ 开启 | 30天无活动自动归档 |
| **审批推送** | ✅ 开启 | 推送需要审批的内容 |
| **每日摘要** | ✅ 开启 | 每日推送工作摘要 |
| **任务提醒** | ✅ 开启 | 推送任务到期提醒 |
| **系统告警** | ✅ 开启 | 推送系统异常 |
| **内容渲染** | ✅ 开启 | 自动渲染内容预览 |
| **自动发布** | ❌ 关闭 | 内容自动加入发布队列 |

### 1.2 预设模式

```
!quick     → 极简模式（关闭所有通知和详情）
!normal    → 正常模式（默认设置）
!verbose   → 详细模式（开启所有详情）
```

### 2.1 查看设置

```
!settings

```

│ 对话摘要        │  ✅   │ 自动生成摘要           │
│ 自动归档        │  ✅   │ 30天无活动归档         │
│ 审批推送        │  ✅   │ 推送审批内容           │

└─────────────────┴───────┴────────────────────────┘

修改: !settings <项> on/off
预设: !quick | !normal | !verbose
```

### 2.2 修改单项设置

```
!settings <项> on
!settings <项> off
```

**可用项名**：
- `progress` / `进度`
- `logs` / `日志`
- `summary` / `摘要`
- `archive` / `归档`
- `approval` / `审批`
- `daily` / `每日`
- `reminder` / `提醒`
- `alert` / `告警`
- `render` / `渲染`
- `auto-publish` / `自动发布`

**示例**：
```
!settings progress off
→ ✅ 进度条已关闭

!settings logs on
→ ✅ 详细日志已开启

!settings 摘要 off
→ ✅ 对话摘要已关闭
```

```

关闭所有通知和详情，极简回复。

- 只有核心回复

## 三、各设置项详解

### 3.1 进度条 (progress)

**功能**：显示任务执行进度

**示例对比**：

```
❌ 关闭时：
用户: 帮我做个飞书机器人
AI: 好的，已完成！代码已生成。

✅ 开启时：
用户: 帮我做个飞书机器人
AI: 好的，我来帮你开发飞书机器人。
⏳ [1/5] 分析需求...
⏳ [2/5] 设计架构...
⏳ [3/5] 生成代码...
⏳ [4/5] 编写测试...
✅ [完成] 开发完成！
```

### 3.2 详细日志 (logs)

**功能**：显示 AI 执行的具体步骤

**示例**：

```
✅ 开启时：
AI: 好的，我来帮你分析这个问题。

📝 执行步骤:
  → 正在读取文件: src/index.ts
  → 发现错误: Line 45, TypeError
  → 分析原因: 未处理空值
  → 生成修复代码

修复方案已生成。
```

### 3.3 对话摘要 (summary)

**功能**：自动生成对话摘要写入 Project

**示例**：

```
✅ 开启时：
（对话 10 轮后）
📋 已生成对话摘要

## 对话摘要
时间: 2026-07-20 10:00-10:30
轮次: 1-10

主要内容:
- 用户需要开发飞书机器人
- 支持消息推送和指令处理
- 需要部署到自有服务器

下一步: 开始编码实现
```

### 3.4 自动归档 (archive)

**功能**：30 天无活动的 Project 自动归档

**示例**：

```
✅ 开启时：
📦 项目「XXX」已归档

归档时间: 2026-07-20
原因: 30天无活动
状态: 已保存到归档

查看归档: !archive list
恢复项目: !project resume <id>
```

### 3.5 审批推送 (approval)

**功能**：推送需要你审批的内容到 #审批 频道

**示例**：

```
✅ 开启时：
#审批 频道收到：

⏸️ 需要审批: 报价单

项目: 飞书机器人开发
客户: XXX 公司
金额: ¥120,000

[批准] [修改] [拒绝]
```

### 3.6 每日摘要 (daily)

**功能**：每日推送工作摘要到 #提醒 频道

**示例**：

```
#提醒 频道（每日 21:00）：

📊 今日工作摘要

日期: 2026-07-20

进行中项目: 3
├─ PRJ-001: 飞书机器人开发 (80%)
├─ PRJ-002: 客户报价单 (完成)
└─ PRJ-003: 公众号文章 (草稿)

待办任务: 5
├─ [ ] 部署飞书机器人
├─ [ ] 发送报价单
└─ ...

新增灵感: 2
├─ 「做个 Chrome 插件」的想法
└─ 「AI 代码审查」的想法
```

### 3.7 任务提醒 (reminder)

**功能**：任务到期前提醒

**示例**：

```
#提醒 频道：

⏰ 任务提醒

项目: 飞书机器人开发
任务: 部署上线
截止: 今天 18:00
状态: 进行中

[查看项目] [标记完成] [延后]
```

### 3.8 系统告警 (alert)

**功能**：推送系统异常

**示例**：

```
#告警 频道：

🚨 系统告警

类型: Pi RPC 连接断开
时间: 2026-07-20 15:30
影响: 当前对话中断

自动重连中... (尝试 1/3)

[查看详情] [联系支持]
```

### 3.9 内容渲染 (render)

**功能**：自动渲染内容预览

**示例**：

```
✅ 开启时：
📄 已生成公众号预览

标题: AI Agent 的前世今生

[预览图片]
[查看完整预览] [发布] [修改]
```

### 3.10 自动发布 (auto-publish)

**功能**：内容自动加入发布队列（需谨慎开启）

```
⚠️ 警告：开启后将自动发布内容

确认开启？
!settings auto-publish confirm on
```

## 四、频道与通知

### 4.1 通知频道

| 频道 | 内容 | 设置控制 |
|------|------|---------|
| #审批 | 审批卡片 | `approval` |
| #提醒 | 每日摘要、任务提醒 | `daily`, `reminder` |
| #告警 | 系统异常 | `alert` |

### 4.2 通知免打扰

```
!dnd                    - 开启免打扰（30分钟）
!dnd 1h                 - 免打扰 1 小时
!dnd off                - 关闭免打扰

!dnd recurring          - 设置每日免打扰时间
!dnd recurring 22:00-08:00
```

**免打扰期间**：
- 审批推送 → 合并延迟
- 任务提醒 → 延迟到结束后
- 每日摘要 → 延迟
- 系统告警 → 仍会推送（除非关闭 `alert`）

## 五、项目设置

### 5.1 项目级设置

每个 Project 可以有独立的设置，覆盖全局设置：

```
# 项目内命令
!project settings       - 查看项目设置
!project settings progress off   - 该项目关闭进度显示
!project settings summary on    - 该项目开启摘要
```

### 5.2 项目设置模板

```yaml
project_settings:
  # 该项目的设置会覆盖全局设置
  project_id: PRJ-2026-0001
  
  overrides:
    progress: true      # 覆盖全局
    logs: false        # 覆盖全局
    # summary: 未设置 → 使用全局
```

## 八、常见问题

### Q: 关闭所有通知后如何查看审批？

```
A: 使用命令查看：
   !approvals          - 查看待审批
   !approvals pending  - 查看待处理
```

### Q: 不想看到任何进度条但想看摘要？

```
A: 组合设置：
   !settings progress off
   !settings summary on
```

### Q: 如何只保留核心回复？

```
A: 使用 !quick 模式：
   !quick
```

### Q: 误操作关闭了所有设置怎么办？

```
A: 恢复默认：
   !reset
   或
   !normal
```
