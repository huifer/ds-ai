# 快速开始指南

> 新用户入门手册 - 5 分钟了解系统

---

## 一、你只需要记住一件事

**所有对话都在 `#主入口` 进行**

不需要记住其他频道，不需要记住命令，想到什么就直接说。

---

## 二、基本用法

### 2.1 问问题

```
你: 飞书机器人怎么做？
AI: [直接回答你的问题]
```

### 2.2 让我帮你做事

```
你: 帮我做个飞书机器人
AI: [开始帮你开发，完成后告诉你结果]
```

### 2.3 创建项目

```
你: 帮我做一个客户报价，他们想做飞书知识库，预算50万
AI: 📦 已创建项目「XXX公司-飞书知识库」
    [自动记录客户信息，开始报价流程]
```

### 2.4 写内容

```
你: 帮我写一篇关于 AI Agent 的公众号文章
AI: [开始创作，完成后推送到 #内容-公众号]
```

## 三、我会做什么

### 3.1 自动理解你的意图

```
你: 帮我做个飞书机器人
AI: 理解：你需要开发一个飞书机器人
     → 自动创建项目
     → 开始编码
     → 完成通知
```

### 3.2 自动记录重要内容

```
你: 客户叫 XXX 公司
AI: ✓ 已记录到当前项目
```

### 3.3 自动生成摘要

对话结束后，我会自动生成摘要保存在项目里，方便以后回顾。

## 四、常用命令

### 4.1 查看设置

```
!settings          - 查看当前设置
!quick            - 极简模式
!normal           - 正常模式
```

### 4.2 查看项目

```
!project          - 查看当前项目
!project list     - 查看所有项目
```

### 4.3 其他

```
!help             - 获取帮助
!summary          - 生成对话摘要
!settings <项> on/off  - 修改设置
```

## 五、频道说明

| 频道 | 什么时候看 |

## 七、常见问题

### Q: 我说的它听不懂怎么办？

```
A: 说清楚一点，比如：
   ✗ "帮我做那个"
   ✓ "帮我做一个飞书消息推送机器人"
```

### Q: 不知道该用什么命令？

```
A: 不需要记命令，直接说你想做什么就行。
   比如："我想看我的项目" → 我会帮你列出项目
```

### Q: 想看之前做的东西？

```
A: 说"帮我看看项目列表"
   或说"看看我最近做了什么"
```

## 八、极简模式

如果只想安静地对话，不想被打扰：

```
!quick
```

关闭所有通知和进度显示，只保留核心回复。
