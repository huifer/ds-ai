# 第 1 章 项目总览与学习方法

> 本章回答三个问题：**为什么**要做这件事、**学完之后**你会得到什么、以及**如何**最有效率地使用本仓库。

## 1.1 为什么写这个项目

如果你读过任何一本经典数据结构教材（CLRS、《数据结构》严蔚敏），你大概率有过这样的体验：

> 堆、树、图……学完了，习题也做了。然后有一天打开 PyTorch 源码，或者读到一篇 LLM 系统优化的博客，突然发现——**这些结构全都在那儿**。

但教材往往只教"结构本身"，不教"结构在 AI 里干什么"。结果是：

- 你知道 **Binary Heap** 是 `O(log n)` 插入；
- 但你不一定能立刻反应：**Beam Search** 就是用堆实现的；
- 你知道 **Hash Table** 平均 `O(1)`；
- 但你不一定知道：**Attention** 里 Q·K 的结果，本质上就是一次 Hash Lookup。

本项目要补上的就是这个**断层**。

## 1.6 章节约定

每个章节统一按以下结构展开：

```markdown
# 第 N 章 [数据结构名] ([English Name])

> 一句话定义本章要解决的问题

## 是什么
## 为什么（AI 中的角色）
## 怎么用（最小示例）
## 复杂度与权衡
## 延伸阅读
```

阅读时请留意：

- **是什么**：以最少篇幅说清楚结构本身
- **为什么**：重点章节，列出该结构在 AI 中的 3-5 个典型场景
- **怎么用**：可运行的最小代码，建议跟着敲一遍
- **复杂度**：Big-O + 在 AI 系统中实际表现
- **延伸阅读**：论文 / 博客 / 源码链接
